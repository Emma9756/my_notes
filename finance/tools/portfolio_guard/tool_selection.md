# 现成工具调研与选型

调研日期：2026-06-08

## 结论

没有找到能直接覆盖以下组合需求的现成工具：

1. 单一平台：银河证券场内。
2. 多市场：A 股、港股、黄金、债券。
3. 多类型：场内 ETF、LOF、个股、现金。
4. 按自定义目标配比和回撤/上涨规则，输出具体加仓/减仓金额。

因此本目录采用轻量自建方案：`portfolio_guard.py`。

## 候选工具

| 工具 | 适合场景 | 不足 |
|---|---|---|
| Ghostfolio | 自托管资产跟踪，多账户、交易导入、组合分析 | 对银河场内持仓、A 股/港股代码口径和中文投资规则适配仍需维护；没有内置规则型买卖金额提示 |
| Portfolio Performance | 桌面端长期记账、绩效分析、IRR/TWR 等 | 不是服务型工具；自动行情和中文证券代码口径仍需维护；不直接生成买卖金额建议 |
| Wealthfolio | 本地优先、隐私友好的组合跟踪 | broker sync 偏海外生态；中文券商和 A 股/港股代码适配弱 |
| AKShare | A 股、港股、美股、基金、指数等行情数据接口 | 是数据接口库，不是组合管理应用 |
| PyPortfolioOpt | 组合优化、预期收益、风险模型、有效前沿 | 是优化库，不负责本地持仓、平台聚合和规则提示 |
| VectorBT | 快速回测、策略分析、多标的向量化计算 | 是量化回测工具，不是个人资产台账 |

## 为什么自建

个人组合管理的关键痛点不是“有没有漂亮的报表”，而是：

```text
我的实际持仓分散在哪里？
当前各类资产偏离目标多少？
如果今天要操作，应该看哪些标的、买卖金额大概是多少？
```

这些逻辑和个人平台、目标配比、可用现金、阈值规则强相关。重型系统需要大量适配；轻量 CSV/YAML 工具能先把决策闭环跑起来。

## 当前边界

- 当前不自动登录银河证券。
- 当前不自动下单。
- 当前联网行情通过 AKShare 获取公开历史行情，不保证实时逐笔行情。
- 输出是规则型提示，不构成投资建议。
