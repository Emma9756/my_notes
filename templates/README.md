## 模板

Obsidian 笔记模板，用于快速创建标准化笔记。

### 文件

```
templates/
└── general_template.md          # 通用笔记模板（含标题/日期/标签/frontmatter）
```

### 使用方式

在 Obsidian 中通过 Templater 插件调用，自动填入标题和日期。frontmatter 默认标签包括 `理财` `健身` `LLM` `from_codex`，按需删减。

### 计划

- `review_template.md` — 周/月复盘模板
- `comparison_template.md` — 产品对比模板（基金/ETF 等）
